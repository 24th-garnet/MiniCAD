# 機能の出どころ別一覧

**何が「ワイヤーの要求」で、何が「我々の判断」なのかを分ける表です。**

これまで `status.md`（実装の現在地）と `questions.md`（確認したいこと）の
2 つで足りると思っていましたが、どちらも**出どころを区別していません**。
そのため「一般的な CAD にあるから入れよう」と自分で決めたものが、
いつのまにか「宿題」として一覧に残り続けていました。

| 区分 | 意味 |
|---|---|
| **A** | **ワイヤーに書いてある。** 要求 |
| **B** | ワイヤーには無いが、**一般的な CAD にはある。** 我々が倣って決めたもの |
| **C** | どちらにも無いが、**我々の事情で必要。** 連携・規律・契約 |
| **D** | **要らなくなった／要らないのに、実装してある。** 整理の対象 |

突き合わせたワイヤーは `ワイヤー/クライアント/20_案件詳細_現状図面（作成_編集_削除）_20261005.pptx`
の 8 枚すべてです。番号つきの項目は [questions.md](questions.md) の番号です。

**4 枚がモードで対になっています。** ここを読み違えて 3 度間違えたので、
対応を先に書いておきます。

| スライド | 中身 |
|---|---|
| 1・2 | 入出力・互換性 |
| 3・4 | 一覧と覚え書き |
| **5 / 6** | **3D**（プロ / **通常**） |
| **7 / 8** | **2D**（プロ / **通常**） |

**部品パレットの全量は 6 枚目と 8 枚目の両方にあり、8 枚目が改訂版**です
（「シングルドア→開き戸(片開き)に名称変更」「U型窓 削除」「出窓壁 削除」など、
施主の赤入れが入っています）。**7 枚目の長い作図一覧はプロモードのもの**で、
通常モードが求めているのは 8 枚目の「ペイント：直線 / 矩形 / 曲線 / 外部領域」
の 4 つだけです。

| ダブルライン／ダブルライン多角形 | **1 つの実体**（`DoubleLineShape`：中心線と幅）。見える 2 本はそこから作り、**置いたあとに間隔だけを変えられます**。頂点編集は中心線に効きます。**倣う先が機能していないので倣いませんでした**——AutoCAD の MLINE も幅は作図時の変数で決まり、置いたあとに変えるのは素直にいきません。互換の歴史から来る制約で、我々には無いので |
| 長円 | **両方の読みを名前で分けました**（2026-11-17）。「楕円」＝真の楕円、「**長円（小判型）**」＝角丸四角形の角を短辺の半分まで丸めたもの。日本の製図では**長円＝小判型**（JIS の長円穴）を指すのが普通ですが、倣い先の Vectorworks の Oval ツールは**真の楕円**で小判型ではありません。**どちらの読みでも作れるようにして、名前で区別**しました。小判型は `roundRectRadius` が短辺の半分で頭打ちにするので、**新しい種別は要りません** |
| 結合 | **交点まで伸ばします**（2026-11-17）。端点が合っていればそのまま、合っていなければ端の線分を伸ばした先の交点まで動かして繋ぎます。**「動かす側」を選べます**（両方 / 1 本目だけ）——Vectorworks が Dual / Single を分けており、寸法や通り芯に合わせてある側を固定したいことがあるためです。**伸ばす上限はその線分自身の長さまで**。上限が無いと、ほぼ平行な 2 本が画面の外で繋がります |
| 2D の図形加工 | 基準点 xy（**z はグレーアウト**）／サイズ／回転 |
| 原文の文言どおりで足りているもの | **角の丸め**「2つの線分や図形（2辺）の角を丸める」／**消しゴム**「**2D図形**の一部を切り欠いたり、図形を分割したり」／**引出線付き注釈**「引出線のついた注釈の作成（ダイアログ…入力の上、配置）」／**フライオーバー**（項目名のみ。「歩く」で目線の高さに下りる。**同名に見える「ウォークスルー」は別項目**で、仕様 1 枚ぶんがあり、倣って作りました） |
| 3D の編集 | **プッシュ/プル**（上下・側面とも。縦の角を落とした立体も元の辺なら押せます。丸い面と面取りの面は断り、理由を画面に出します） |
| 3D 作図（5 枚目・プロ / 6 枚目・通常） | **作図面の上に多角形を描いて立体にする**（ビュータブの「描く」）／視点移動・回転／中心モード 4 つ／**基本形状の挿入 8 種**／移動／複製（**複製先のレイヤーを選択**）／鏡像／配列複写／基準点 xyz／サイズ／**回転 X / Y / Z**／合成（結合）／切り欠き／**分割 / 分解**／**テーパ・3D フィレット・3D 面取り**（上下・縦とも）／3D 多角形／**作業面**（斜面に沿って置く） |

## B. ワイヤーに無く、一般的な CAD にあるもの

### B-1. 倣って入れた（実装済み）

**ワイヤーは求めていませんが、無いと CAD として使えないので入れたものです。**

| 項目 | なぜ入れたか |
|---|---|
| **undo / redo** | 無い作図ツールは使えない |
| **スナップ**（端点・中点・交点・中心・壁・格子・角度） | ワイヤーが書いているスナップは **2D 基準点だけ**。実際に線を引くには他も要る |
| **拘束**（平行・直角・同一直線など） | 引き直しのたびに角度が狂う |
| グリッドの表示と吸着 | 同上 |
| **実寸印刷**・用紙と表題欄 | 「縮尺」が仕様にあるので、紙に出せないと意味がない |
| 線群（細線・太線・極太線） | 1 枚目の「線関連（種類/太さなど）」の互換に必要 |
| 図面ビュー（複数の図面） | レイヤー表が図面ごとに縮尺を持つ形を素直に読むとこうなる |
| **立面図・断面図・展開図の中身** | 入口（立面ビュー）は仕様にあるが、中身の仕様は無い |
| **部屋の自動検出と面積** | 積算に要る |
| トリム・延長・切断 | 製図の基本動作 |
| DXF の Shift-JIS（Jw_cad 用） | 日本の現場で読めないと互換の意味が薄い |
| **円弧壁** | **5 枚目**の補足が「例）壁、**円弧壁**、壁結合などは、通常モードを利用する前提」と名指ししている。壁ツールの「種類」で 3 クリック（始点・終点・通る点）。中心は持たず膨らみ（`tan(掃過角/4)`）で表す |
| **階の切り替え**（追加・床高・階高・下階の下敷き） | **ワイヤーに記述なし。** データは前から複数階を持てたが、切り替える UI が無いと 2 階建ての物件を通しで起こせない。2D は作業中の階だけを描き、3D は全部の階を積む |

| **3D の頂点・辺へのスナップ** | **2026-11-17 に入れました。** ワイヤーに記述が無いので要るかどうかから伺い、要るとお返事をいただきました。AutoCAD に倣い、2D とは別のトグル（`settings.snap3d`）・種別 6 つ（頂点 / 辺の中点 / 面の中心 / 辺の上 / 面の上 / 格子）・候補が複数なら `Tab` で送る、の 3 点。**画面の画素で測ります**——世界の mm で測ると、同じ 100mm でも奥の角に強く吸い寄せられます |

## D. 要らないのに実装してあるもの

### 消したもの（11 件）

**宣言したきり、本番からもテストからも 1 度も呼ばれていなかったもの**を、
`src` 全体を機械で走査して洗い出しました。残りは 0 件です。

| 消したもの | 置き場 | なぜ死んでいたか |
|---|---|---|
| `fixtureSnapPoints` | `core/fixture.ts` | `core/snap.ts` に "fixture" の文字が 1 つも無く、構造物はスナップ候補に入っていなかった。**直したつもりで効かない罠** |
| `verticalRange` | `core/fixture.ts` | 3D が `baseOf` + `localRange` に移ったあと、**テストだけが呼んでいた**（下記） |
| `distSq` / `rectCorners` / `arcPoint` | `core/geometry.ts` | 作りかけの道具。輪郭は `localOutline`、ブロックは `instanceVertices` が受け持つようになった |
| `leaderTextAngle` | `core/leader.ts` | 常に 0 を返すだけの関数 |
| `hasAttrsFor` | `core/material.ts` | インスペクタは `attrsOf` を直に呼んでいる |
| `pointFromPolar` / `resolveSnapNode` | `core/snap.ts` | 数値入力とノード解決が別の道へ移ったあとの残骸 |
| `saveLocal` | `io/scene.ts` | `saveLocalFile` に寄せたときの取り残し |

**`verticalRange` がいちばん性質が悪いものでした。** 本番は使っていないのに
テスト 5 箇所が呼んでいたので、**本番が壊れてもテストは通ります。**
テストのほうを「本番が立体を置くのと同じ道」（`baseOf` + `localRange` +
`level.floorZ`）に書き換えてから消しました。
