# 実装の確認表

**ワイヤーが求めている機能が、使い物になる形で入っているか**を、1 項目ずつ
見ていただくための表です。

この表の出どころは [coverage.md](coverage.md) の **A 区分**（＝ワイヤーに
書いてある要求）だけです。我々が一般的な CAD に倣って足したもの（B 区分）は
**入れていません**——要求ではないものを評価していただくと、限られた時間が
そちらに流れます。

## 使い方

- **○ / △ / × の 3 つ**で付けてください。△ は「あるが足りない」です
- **× と △ には、できれば一言**。「何が足りないか」が無いと直せません
- **図面の上のことは、コメントで残せます。** ツールバーの **コメント (J)** で
  点をクリックすると本文を書けます。場所と結びつくので、文章より早いです
- 分からないところは `×` ではなく **`?`** にしてください。**探せなかったのは
  実装の問題**で、我々が直すべきところです

**プロモードに切り替えてください。** 画面上の「プロモード」を押すと道具が
9 本増えます（オフセット・トリム・延長・切断・変形・配列複写・スポイト・
ソリッド・点）。既定は通常モードなので、押さないと**半分が見えません**。

## 先に知っておいていただきたいこと

- **「使い方」に「いまできないこと」が並んでいます。** そこに書いてあるものは
  **評価の対象外**です（U 型出窓、円弧壁への拘束・トリム・延長、壁の角の丸め、
  素材の柄、写実レンダリング、PDF 変換、3D の中で線を描く、3D の頂点スナップ）
- **この図面は検討と伝達のためのものです。** 確認申請図書や施工図として
  使えるかどうかは検証していません
- **このリンクからは図面を取り出せません**（DXF・SVG の書き出しは持ち主の
  画面にあります）。**入出力の往復は、そのため評価できません**——
  必要なら書き出しを許したリンクを別にお渡しします
