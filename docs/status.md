# 実装状況 — ワイヤーとの突き合わせ

madoriba の画面仕様（`ワイヤー/クライアント/20_案件詳細_現状図面`）に対して、
作図エディタ（MiniCAD）が**いま何を持っていて、何を持っていないか**。

ワイヤーの項目名をそのまま見出しにしてあるので、仕様書を横に置いて追えます。

> **どの枚を見ているか。** 機能一覧は 2 組あります。5・6 枚目が最初の版、
> **7・8 枚目が改訂版**で、2 枚目が「6 ページ、8 ページ目参照」「5 ページ、
> 7 ページ目参照」と後者を指しています。**この文書は 7・8 枚目に合わせてあります。**
> 改訂版で `削除` と書かれた項目は「無い」ではなく**仕様から外れたもの**として
> 扱い、そうと分かるように書いてあります。

- **✅ ある** — 画面から使えて、テストで固定してある
- **◐ 一部** — 一部だけある。何が無いかを行に書く
- **❌ ない** — 無い。理由を書く
- **— 射程外** — MiniCAD の仕事ではない（ホストまたは別サービス）

> **読み方の注意。** 「❌ ない」に理由が書いてあるものは、**作り忘れではなく
> 判断の結果**です。仕様と違う判断をしたものは「仕様と違う判断をしたところ」に
> まとめてあります。そこは**確認をお願いしたい箇所**です。

## 2. 通常モード — オブジェクトの挿入

8 枚目（改訂版）のパーツ表の順に並べてあります。`削除` と書かれた項目は
**仕様から外れたもの**なので「無い」とは数えていません。

> **パーツ表はひととおり並びました。** 8 枚目の品名がそのままパレットの
> ボタンになっていて、1 クリックで既定値（幅・窓台・枚数・符号・張り出し）ごと
> 選べます。`OpeningKind` を増やしたのは**丸窓 1 つだけ**で、残りは
> 「既存の種別 ＋ 既定値の組」で出しています。天窓は壁に付かないので
> `Opening` ではなく**構造の側**に置いてあります。

### ペイント

> **読み方を直しました。** ここは汎用図形ではなく**壁を描く道具**です。根拠は 3 つ。
> ①`Wall.base` のコメントに奥谷さんの ※1「床からの距離を足してツール数を減らす」が
> そのまま引かれている ②奥谷さんご自身が「**直線ツールで非耐力壁**、壁厚の変更で
> パイプスペースは作れる」と書いている ③7 枚目の補足が「例）壁、**円弧壁**、壁結合などは
> 通常モードを利用する前提」と円弧壁を名指ししている。
> 前の版は汎用図形（線・円弧）に当てていました。**取り消します。**

## 3. プロモード — 2D 作図

7 枚目が「ベクターワークスのような機能」として一覧にしているもの。
**基本操作と編集はあらかた揃っていて、作図の形がまだ足りません。**
新しい作図は**プロモードの「作図」ツール（F）に「種類」セレクタでまとめて**います。

### 基本操作

| 項目 | | |
|---|---|---|
| 選択 | ✅ | |
| 画面移動 | ✅ | |
| **用紙移動**（図形を動かさず用紙を動かす） | ✅ | 「用紙と表題欄」の**用紙の左下 X / Y** で動かします。「図面の中央に合わせる」も残してあります。**用紙枠をドラッグでは動かせません**——選択ツールが「掴んで動かす」ものをもう 1 つ持つと、**図面を動かすつもりが用紙を動かしていた**という取り違えが起きます（頂点編集を別ツールにしたのと同じ理由）。用紙の位置は一度決めたらほとんど動かさないので、数値のほうが合っています |
| 移動（ドラッグ）・複製 | ✅ | |
| **複製先のレイヤーを選択** | ✅ | 「複写」と「配列」のオプションバーの**複製先の画層**。空欄は「元のまま」で、画層を指すのとは別の状態です。**複製したものだけが移り、元は動きません**（移動では複製先が無いので出ません） |
| 回転（移動 / 複製） | ✅ | |
| 反転（移動 / 複製） | ✅ | 鏡像 |
| **2D 基準点**（印刷に出ない位置合わせ用の点） | ✅ | 点ツール（Q）。**印刷に出ない画層**（`A-DRAFT`）に置くので、画面には出ますが SVG・DXF・印刷には出ません。近くへカーソルを持っていくとスナップが行きます |
| シンボルの配置 | ✅ | 下記 6 |
| 配列複写（格子状・円周上） | ◐ | 「配列」ツール。**ワイヤーは 3D の節に書いていますが、ソリッドとは無関係**で 2D でも動きます。**向きを変えずに円周へ並べることはできません**——複写は選択全体に 1 つの変換をかける造りで、「位置だけ回して向きは保つ」は 1 つの変換では表せません |

### 編集・加工

| 項目 | | |
|---|---|---|
| オフセット | ✅ | 線・折れ線・円弧・円、**壁にも効きます** |
| トリミング | ✅ | |
| 延長 | ✅ | |
| 変形（頂点の移動・削除・追加） | ◐ | 「変形」ツール（Z）。線と折れ線の頂点をドラッグ、辺をダブルクリックで追加、Delete で削除。壁は途中をクリックで角が増え、角そのものは選択ツールでそのまま掴めます。**円弧・円・楕円・正多角形・角丸には頂点がありません**（直すのは中心や半径で、プロパティ欄の仕事） |
| 結合 / 合成 | ◐ | **結合**（「角」ツール A の種類）は端点が合っているものを繋ぎます。図形は 1 本の折れ線に、壁は**一直線に並んでいるときだけ** 1 本に（開口の位置は保たれます）。**合成**（閉じた図形どうしのブール演算）は、図形を 2 つ以上選ぶとプロパティに**合成 / 切り欠き / 交差**が出ます（`core/polybool.ts`）。辺を共有する・頂点が辺に乗る・接するだけ、といった**退化を正面から扱います**——間取りの図形では例外ではないので。**穴ができる形と 2 つに割れる形は断ります**（`Shape` に穴の置き場が無いため。理由を画面に出し、図面は 1 つも変えません） |
| 角の丸め（フィレット） | ◐ | 「角」ツール（A）。**図形どうしだけ**です——壁は `Wall` が直線で、円弧の壁がまだ無いので丸めた円弧を置く先がありません。断って理由を出します |
| 面取り | ✅ | 「角」ツール（A）。**図形にも壁にも効きます**。壁は線に差し替えず、端のノードを動かして短くし、あいだに新しい壁を 1 本置きます |
| 消しゴム（一部を切り欠く・図形を分割する） | ◐ | 「切断」ツール（P）の種類で選びます。**分割**は図形も壁も交わっているところで分け、**消しゴム**は図形の上をドラッグした範囲を消します——交点が無くても動きます。壁の途中を消すのはまだできません |

**図形の編集（基準点・サイズ・回転・グループ・色・素材・積算・レイヤー・
シンボル）は 3D と同等**、と 7 枚目は書いています。下記 4〜9 のとおりで、
残っているのは**色（任意色とスポイト）**だけです。

| 各種中心モード | ✅ | 3D のビュータブで選びます（全図形 / 選択したもの / クリックした位置 / 原点）。**回す中心が移るだけ**で、見ている向きと距離は変わりません |
| フライオーバー | ◐ | 「歩く」で目線の高さに下りて水平を向きます。**歩き回るのはドラッグと平行移動**で、WASD のような専用の操作はありません |
| **基本形状の挿入**（直方体・三角柱・円筒(垂直)・円筒(水平)・円錐・球・半球） | ✅ | プロモードの**「ソリッド」ツール**。**`Fixture` の一般化**で、角柱が直方体の、円柱が垂直の円筒の特例になっています。平面の記号・3D・ピック・積算・JSON・DXF は構造物と**同じ道**を通ります。**3 軸で回ります**（プロパティ欄の回転 X / Y / Z）。倒すと平面の記号は上から見た形（投影）になります。注意が 1 つ：**平面では円筒・円錐・球・半球が同じ円に見えます**——一般的な CAD の平面図も同じなので、区別は「種類」欄とプロパティで（[questions.md](questions.md) の 12） |
| 3D の中での作図（作図面・グリッド） | ◐ | **3D の中に基本形状を置けます**（3D のビュータブの「置く」）。いま指している面がそのまま作図面になり、その面の上に格子が出て、置く前に仮の姿が見えます。**作図面が立体の向きも決めます**——斜面を指せば斜面に沿って置かれます（ワイヤー「斜面を作業面として設定すると、配置するときに回転する必要がなくなる」）。**作図面の上に多角形を描いて、その場で立体にできます**（3D のビュータブの「描く」）——ワイヤー ※3「3D多角形で作成した 2D に対してプッシュ/プルで高さを与えて立体化する」。描いた多角形は**傾きつきの押し出し立体**になるので、新しい実体は足していません。**線は 2D で引きます**（`Shape` は 2D なので、立った面に引いた線の置き場がありません）。スナップは**格子と面の上まで**で、頂点や辺には吸い付きません——候補がすぐ数百になる（サンプル間取りで 260 面）ため。足りないことは画面の下に出します |
| **押し出し** | ✅ | 閉じた図形を選んで、プロパティの**「押し出す」**で立体にします。**凹でもそのまま立ちます**（三角形分割は要りません）。**自己交差した形は断ります**——塗り（nonzero）と当たり判定（偶奇）が重なった部分で食い違うため。元の図形は消えます（立体が平面にも同じ輪郭を描くので、残すと線が二重になります）。undo 1 回で戻ります |
| **プッシュ/プル** | ✅ | 3D で**Alt+ドラッグ**。上面を押せば背が伸び（下端は動かず）、下面を押せば下端が下がります（上端は動かず）。壁の天端は今までどおり修飾なしでも動きます。**倒した立体でも効きます**——上下左右は「立体にとっての向き」で見るので、倒して法線が斜めを向いても上面を掴めます。**側面は輪郭の辺を 1 本ずつ**動かせます（三角柱でも、押し出した形でも）——動かした辺を両隣の辺の線と交わらせて形を閉じ直し、**幅と奥行も追従**します。**縦の角を落とした立体でも、元の辺なら押せます**——`cutCornersDetail` が「見えている辺が元のどの辺か」を返すので、掴むのは落とした後の面、書き戻すのは落とす前の輪郭、という往復ができます（箱は寸法のまま扱うので、大きさを変えれば面取りが付いてきます）。断るのは**丸い種別**（曲面の押し引きは SketchUp にも AutoCAD にもありません。直径はプロパティのサイズ欄で変えられます）、**面取りの面そのもの**（MiniCAD は面取りを「形」ではなく「寸法」として持つので、その面を動かした結果を輪郭で表せません）、**輪郭をまっすぐ押さない種別**（階段・スロープ）だけで、**断った理由は 3D の状況表示にそのまま出ます**。**隣の頂点を追い越す量は断ります**——面積の符号では捕まりません（三角形の底辺を頂点の向こうまで押すと、小さい三角形が反時計回りのまま残ります） |
| **合成・切り欠き（ブーリアン）** | ✅ | 立体を 2 つ以上選ぶと、プロパティに**合成 / 切り欠き / 交差**が出ます。**結果の形ではなく「作り方」を持ちます**——相手は母体の中にしまい込まれ、図面からは消えるので、平面にも積算にも二重に出ません。**「分解」でいつでも戻せます**。22 段の面を割る木がそのまま土台です |
| **立体を 2 つに切り分ける** | ✅ | 立体 1 つと**線 1 本**を選ぶと「切り分け」が出ます（断面図と同じ作法。専用ツールは増やしていません）。**新しい実体は要りませんでした**——平面で切るのは半空間と交わるのと同じで、立体を丸ごと覆う箱との**交差 2 つ**で表せます。母体の種別・大きさ・輪郭は元のままなので、平面の記号も積算も壊れません。**切り口は平面にも出ます。** 既に作り方を持つ立体も、その作り方ごと中へしまって切れます。線が立体を横切っていなければ断ります |
| 切り欠いた形を平面の記号に出す | ✅ | 影どうしのブール演算で起こします。**上から見て本当に変わるときだけ**出します——合成はいつでも、切り欠きは相手が母体の高さを**突き抜けている**とき、交差は高さが**重なっている**とき。箱の真ん中だけをえぐっても上から見れば箱のままなので、そういう切り欠きは平面に出しません。**穴が開く形と 2 つに割れる形は、切り欠く前の形のまま**です（輪郭に穴の置き場が無いため）。当たり判定が毎フレーム呼ぶので、**指紋で覚えています**（実測：円柱どうしの切り欠き 60 個で 11ms → 0.31ms） |
| **テーパ / 3D フィレット / 3D 面取り** | ✅ | 立体のプロパティの**稜線の仕上げ**で、テーパ・面取り・角の丸めを付けられます。**「どの稜線か」（上下 / 縦 / 両方）を選べます。** 上下は押し出す途中の輪郭を何段かに分ける形、**縦は平面の輪郭の角を落とす**形——角柱の縦の稜線は輪郭の頂点そのものなので、B-rep は要りませんでした。**縦を落とすと平面の記号にも出ます**（面取りした柱は平面でも八角形になります）。テーパは「上へ行くほど細くする」仕上げなので縦には効かず、画面でも選べません。**輪郭を押し出す種別だけ**が対象で、階段・スロープ・回転体には付けられません |
| 3D 多角形 | ✅ | **凹でも、任意の平らな多角形が 1 枚の面になります。** 押し出した L 字の上面がそのままそれにあたり、3D に出て、クリックで拾えて、DXF にも出ます（内部の切れ目は隠します）。**法線はニューウェル法**で出すので、頂点の並びをどこから始めても裏返りません——裏返ると見えているのにクリックが素通りします。**厚みの無い面だけを単体で置くことはできません**（[questions.md](questions.md) の 14） |
| ソリッドどうしを食い込ませたときの隠面消去 | ✅ | **面を割る木（BSP）**で塗る順を決めています。交差する 2 つの直方体を 36 方位 × 6 仰角から見て、手前の面が必ず後に描かれることをテストで固定しました |
| 3D の頂点・辺へのスナップ | ❌ | 候補が爆発します（サンプル間取りで 260 面）。**無いことを画面に書いて**あります |

**前の版はここに「深度バッファ・ブーリアンのカーネル・3D の拘束層の 3 つが要るので
汎用ソリッドは作れない」と書いていました。調べ直したところ、3 つのうち 2 つは
成り立っていませんでした。** 根拠が事実でなくなったので、ここも書き換えます。

| 前の版の理由 | 調べた結果 |
|---|---|
| 深度バッファが無いので汎用ソリッドが交差すると破綻する | **交差すれば破綻するのは本当**です。ただし**置くだけなら破綻しません**——7 種類とも 36 方位 × 6 仰角から見て破れ 0（`tests/solid.test.ts` で固定）。しかも**いまの 3D は汎用ソリッドと無関係に画素の約 2 割で嘘をついていました**。原因は深度ソートではなく塗る順の固定で、直して 1〜2% になっています |
| ブーリアンのカーネルが要る | **正しかった**ので、書きました（`render3d/csg.ts`）。合成・切り欠き・交差が動いています |
| 3D の拘束層が要る | **形を置くだけなら要りません。** `Fixture` は壁グラフにも拘束ソルバにも参加していません |

**面を割る木（BSP）は入りました。** ソリッドどうしを食い込ませても破綻しません。
画素ごとに「塗られたものの深さ」と「本当に手前にある面の深さ」を突き合わせると、
**食い違いは 0.00%** です（固定順だった頃は約 2 割、深さ順にして約 1%）。
**WebGL には移っていません**——`ctx` に多角形の fill と stroke しか頼まない、
という契約は守ったままです。

**ブーリアン（合成・切り欠き・交差）・テーパ・切り分け・縦の稜線の面取りも
入りました。** 一度はここに「切り分けにはメッシュを持つ実体が、縦の稜線の
面取りには面の隣り合わせを知る構造（B-rep）が要る」と書いていましたが、
**どちらも要りませんでした**——切り分けは「大きな箱との交差」2 つで表せ、
角柱の縦の稜線は輪郭の頂点そのものでした。本当に新しかったのは
**2D の多角形ブール演算**（`core/polybool.ts`）1 つだけです。

**プロモードは通常モードを狭めません。** 仕様には「通常モードで利用できる機能は
プロモード切り替え時は不要（壁は通常モードを利用する前提）」とありますが、
字義どおりに壁を外すと、通常モードの道具立てを失うだけで釣り合いません。
通常の道具立てはプロでもそのまま出し、**プロは CAD 寄りの道具と汎用ソリッドを足す**形です。

## 11. 画面・権限まわり

| 項目 | | |
|---|---|---|

## 仕様と違う判断をしたところ

**確認をお願いしたい箇所です。** いずれも、仕様のとおりに作ると具合が悪くなる
理由があってそうしています。

### 1. 「レイヤー」をデータとしては「図面」と呼んでいます

仕様の「レイヤー」（躯体図 / 平面配置 / 天井伏図、各々 1/100、透過つき）は、
よく見ると**画層の選択と、縮尺と、不透明度の組**で、CAD の画層そのものでは
ありません。画層は DXF の LAYER に 1:1 で対応していて、LAYER に縮尺はないので、
縮尺を持たせると DXF の相互運用が壊れます。

**画面では仕様どおり「レイヤー」と呼べます**（いまは「図面」と出しています）。
呼び方のご希望があれば合わせます。

### 2. 窓の種別を増やさず、符号で区別しています

片開き窓・上げ下げ窓・FIX窓・排煙窓・横連窓は、**JIS A 0150 の平面図では
同じ記号**（障子線 2 本）になります。種別を足しても図面は変わらず、
同じ記号が並ぶだけです。代わりに**建具符号**（`AW-1` など）・**張り出し**・
**窓台の高さ**・**枚数**で区別し、3D と積算はそれを読みます。
図面には符号が出ます。

**ただし 8 枚目は品名で並べています。** 使う人から見れば「FIX窓を置く」で
あって「窓を置いて符号を付ける」ではありません。**パレット側で品名のボタンを
出し、既定値の組として流し込む**のが、両方を満たす形だと考えています
（上記 2 の表で ◐ としたものがこれに当たります）。

**丸窓と天窓だけは種別を足しました。** 丸窓は記号そのものが違い、
天窓は壁に付かないためです。残りの品はパレットのボタンが
「種別 ＋ 既定幅 ＋ 窓台 ＋ 枚数 ＋ 符号」を流し込む形で出しています。

### 3. 建具の「積算対象外」が効きません

積算側は建具の一覧を**品目の数え上げと、壁面積の控除の両方**に使っています。
建具を外すと「穴が無かったこと」になり、壁の数量が多く出ます。
穴は実在するので外していません。**建具を拾わない指定が要る場合は、
積算側の規約で決める形になります。**

### 4. 吹抜は内法面積を変えません

吹抜は**床面積**から引かれますが、内法面積（壁の内側の広さ）は変えていません。
2 つは別の数字で、片方を書き換えると、立面図・DXF・積算が同じ名前で違うものを
読むことになります。引いたことは積算側のレポートに出ます。
